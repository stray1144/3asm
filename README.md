# Overview
3Asm ("ARCx Assembler A sm" where the "sm" doesn't really mean anything) is a assembler for the ARCx MK.II ISA

# Dependencies
- libcxsh: https://github.com/stray1144/libcxsh (ARCx toolchain library)
- libvacant: https://github.com/stray1144/libvacant (Common tool library)

# Install guide
First you need to install the dependencies and then just run:
```
make
sudo make install
```
